# G1 Control Manual

## 1. Build the Teleoperation Network

Follow the steps in [Teleoperation Network](/Robot_Communication/Readme.md) first.

## 2. Run the Device Manager

```bash
python Device_Data_Manager_Public.py
```

See [Device Manager](/Robot_Communication/MQTT/Device_Data_Manager_Public.py) for details.

## 3. Start the Robot

Start either the real [G1](./UnitreeG1/Readme.md) or the [simulator](./Sim/Readme.md).

## 4. Begin Teleoperation

Click `Request Robot` on the web app, then enter AR/VR to start teleoperation.
